## Five things that would have bitten later

1. **`mir_eval.transcription` wants pitches in Hz, not MIDI.** It derives cents from a
   frequency ratio (`transcription.py:435`). Passing MIDI returns a plausible wrong
   answer: MIDI 40 vs 41 computes as 42.7 cents, inside the 50-cent tolerance, so a
   semitone error would have counted as a *hit*. There is a test pinning this.
2. **basic-pitch cannot be installed alongside the core on this machine.** It requires
   `tensorflow-macos` for `python_version > "3.11"` on darwin, and that wheel stops at
   cp311. Hence ADR 0001's two environments.
3. **basic-pitch does not work out of the box either.** It pins `resampy<0.4.3`;
   resampy 0.4.2 imports `pkg_resources`; setuptools removed that in v81. The CLI dies
   at import until you pin `setuptools<81`.
4. **Its note-event CSV is ragged.** The header names 5 columns but the writer does
   `row.extend(pitch_bend)`, so rows are 4 fields plus one column per bend value —
   17, 72, 18, 69, 21, 65 columns in the captured fixture. A `csv.DictReader` would
   have silently kept the first bend value and dropped the rest. Rows are also not
   sorted by onset.
5. **ruff 0.16 formats Python code blocks inside Markdown**, and wanted to rewrite
   `docs/spec.md`. `docs/**` is now excluded.
