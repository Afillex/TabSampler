# 2026-10-07 — Phase 6: full songs; the README and the report; a dataset search

## Phase 6 — full songs (plan `docs/plans/2026-10-07-phase-6-full-songs.md`)

- **No public dataset pairs full mixes with string labels**, so mixes are built: a labelled take
  over BabySlakh backing with its guitars (and plucked "Ethnic" strings) removed, at 0 and −6 dB;
  BabySlakh songs 1–10 back validation, 11–20 test (ADR 0066). Demucs `htdemucs_6s` separates the
  guitar (ADR 0065); the project now declares its platforms (Apple-silicon Macs, Linux), since
  demucs and PyTorch have no Intel-Mac path.
- **Task 2 (validation, 414 mixes):** pooled E2 — mix 0.1902 / stem 0.3180 at 0 dB, 0.1252 / 0.2572
  at −6 dB; the guitar alone 0.4666. Separation alone cost IDMT's direct-input takes 0.12, and there
  the stem did not beat the mix. Prediction 4 (separation costs 0.02–0.10 pooled) failed: 0.0125.
- **Task 3:** adding a share of the mix back to the stem lowered E2 at every share; the stem alone
  stays.
- **Task 5:** full-song mode on the page and `--full-song` on the CLI; page and CLI agree on a
  validation mix (116 notes).
- **Task 4, the test look** (pre-registered 59cccb8): mixes built (log line 37); scoring started
  (38), interrupted by a power loss (39: restarted), moved back to the CPU after two pre-registered
  checks — the GPU's stems differed from the CPU's by up to 0.0208 on EGSet12 against a CPU rerun's
  0.0176 (40) — and restarted once more after a system crash (41). Still running at the end of the
  day.
- **Fixes on the way, each with a test:** the Demucs model loads once per process; cached stems are
  written whole or not at all (a power cut could otherwise leave a truncated stem to be reused).
- **Found:** demucs's `apply_model` applies one random time shift by default (`shifts=1`), so stems
  are reproducible only from their cache.

## A dataset search, for an accuracy plan

Searched with a self-hosted web crawler; every licence and file list checked at its source.

| dataset | adds | strings | licence |
|---|---|---|---|
| GOAT | 5.9 h real electric, direct input, tab | yes | CC BY-NC 4.0, by request |
| GAPS | 14 h classical guitar, 200+ players, 404 recordings (16.2 GB on HF) | the MusicXML scores carry string and fret on 44–49% of `<note>`s — likely a tab staff doubling the notation, to verify | CC BY-NC-SA (Zenodo); HF tags MIT — conflicting, treated as NC |
| François Leduc | 79 solo jazz guitar recordings, aligned MIDI (0.25 GB) | no | by request for research (Zenodo); HF tags MIT — conflicting, treated as NC |
| Klangio strumming | 90 min acoustic strums | no (chords) | — |

The real, openly licensed data with string labels is already in use; the large new sources are
non-commercial. Ege decided that non-commercial data may train models whose weights are then
published non-commercially, apart from the CC BY electric model, and chose to improve string choice
first (GOAT + GAPS), then the transcriber (GAPS + Leduc + GOAT). The design's data section is agreed;
the rest of the design, the spec and the plan follow.
